## About

I'm the founder of **AxentriX**, a digital systems agency based in Beirut, building full-stack web infrastructure for real estate firms, retail brands, and service businesses across Lebanon and the Gulf.

I don't just ship websites — I build the operating layer behind them: client portals, admin dashboards, e-commerce systems, and the automation that connects them. Every project runs on the same disciplined stack: Next.js, Firebase, and Vercel, deployed and maintained end-to-end by one person.

- 🏢 Founder & Lead Engineer — **AxentriX**
- 🎯 Focus — Client portals, business dashboards, e-commerce platforms, brand systems
- 🛠️ Currently exploring — AI-assisted automation for client onboarding and document workflows
- 📍 Based in Beirut, working across Lebanon, Syria & the Gulf
