## About

I run **AxentriX**, a digital systems agency based in Beirut. I design and build the full stack for SMEs, real estate firms, and retail brands across Lebanon and the Gulf — from the interface down to the database.

My work is centered on one idea: a business needs more than a website — it needs a system. I build that system myself, end to end, on a single consistent stack.

<br>

## Current Focus

- Business systems & client portals for AxentriX clients
- AI-assisted automation for onboarding and document workflows
- Full-stack web development — Next.js, Firebase, Vercel
